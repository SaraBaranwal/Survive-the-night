# Survive the Night

A text-based survival adventure game built in Python.

## About the Game

You wake up alone on a mysterious island after falling from a boat during a storm.

The island appears to be deserted, but you need to explore your surroundings, collect useful items, and make the right decisions to survive the night.

Your choices determine how the story unfolds.

## Features

- Interactive, choice-based gameplay
- Multiple paths and endings
- Inventory system
- Step-based survival timer
- Resource-based decisions
- Different dangers and survival challenges
- Runs entirely in the terminal

## Items

- Torch
- Knife
- Shelter
- Firewood
- Fishnet
- Fish

## Endings

The game has multiple possible outcomes, including:

- Reaching a village
- Surviving the night
- Being killed by a bear
- Being killed by a shark
- Being killed by piranhas
- Dying from the cold

## Technologies Used

- Python 3
